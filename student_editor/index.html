查看正式成员页面 ↗

1 · 连接 GitHub

首次使用请连接 GitHub。账号须已加入实验室仓库并具有 Write 权限。

2 · 基本资料

类别将决定资料显示在哪个 People 页面。变更类别后旧分类中的本人资料会自动移走。

3 · 头像

可直接选择默认头像，也可以上传自己的照片。英文和中文页面共用一张。

选择是即时的；点击“保存并更新本地预览”后才会写入草稿。

4 · 个人简介

Faculty 和博士后可以用 Markdown 编写详细简介。

即时排版预览

5 · 保存、预览与发布

本地草稿可暂缺姓名或头像。正式推送前请补齐中英文姓名并选择头像。推送只合并当前 GitHub 账号对应的 People 条目。
