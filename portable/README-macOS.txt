Zhige Security Lab member editor for macOS

1. Unzip the archive into a writable folder such as Documents. Keep the whole ZhigeMemberEditor folder together.
2. Double-click Start-Member-Editor.command. If macOS asks about an unidentified developer, use Finder's right-click > Open once.
3. In the browser, connect your own GitHub account. The account needs Write access to the lab repository.
4. Fill in your name, category, avatar and descriptions in English and Chinese. Save and preview, then publish.
5. Keep the Terminal window open while editing. Close it when done.

The package includes Python, the Markdown renderer, and GitHub CLI. It runs only on your computer at 127.0.0.1.
The Apple Silicon and Intel ZIPs are separate. Choose the one matching your Mac.
GitHub authorization is completed in your browser. Do not share the .local folder or a used copy of the package.
